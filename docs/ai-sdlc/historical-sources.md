The canonical log contains only this assignment-related session, with provenance references and pre-write secret redaction. `historical_import` means actual stored turns were imported; `documented_summary` is reserved for manually written summaries and is never represented as verbatim conversation.

## Limitations

- Historical coverage is limited to the one relevant local Copilot session found and inspected. This does not establish coverage of other sessions, devices, Copilot surfaces, or ChatGPT history.
- The session-store data contains full message text. Imported records may be truncated at the logger's configured content limit and indicate `content_truncated` when so; timestamps preserve source values when parseable, otherwise are marked `unknown`.
- Redaction uses patterns for common credential fields/token formats and the repository's demo-password shape. It reduces risk but cannot guarantee all secrets are detected. Review the resulting log before sharing it outside the assignment.
- Copilot hook events are configured in `.github/hooks/ai-interaction-audit.json`. Local fixture tests verify normalization, redaction, append, and deduplication. This implementation session observed live prompt, tool, subagent, and stop events in the canonical log, but a new-session verification of startup/end/failure events remains outstanding.
- The importer accepts explicit source paths; directory imports scan only immediate children by default, and recursive traversal requires `--recursive`. The canonical destination log is never accepted as an input source. Dry-run is recommended before append, and `--strict` returns failure when any records or paths are rejected.
